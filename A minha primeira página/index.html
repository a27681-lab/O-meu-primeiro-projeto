Sobre o HTML5 e CSS3

São tecnologias utilizadas para construir páginas web.

HTML cria a estrutura e o conteúdo da página.

O CSS3 serve para aplicar estilos a elementos e etiquetas (tags) HTML.

Principais elementos do HTML

  • Títulos e parágrafos
  • Links
  • Imagens
  • Outros componentes: listas, tabelas, formulários, etc.
  • HTML semântico
